# Session names start with an emoji

Whenever you name or rename a session, the first character is an emoji that
stands for the work: `🩺 prod monitor triage`, `📦 medallion TODO`,
`🔀 #3128 review fixes`. A sidebar full of text-only names is slow to scan,
while an emoji lets you find the right session without reading every name.

Pick from the `visual-formatting` glyph set when one fits, so a glyph means
the same thing everywhere. Use one emoji followed by a space, then the name.
